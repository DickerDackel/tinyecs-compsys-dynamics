# v0.0.5 - PRSA has an offset attribute now

Added an offset attribute to the PRSA

The PRSA now has an offset attribute, allowing for systems to position the
object offset from its prsa.pos without impacting e.g. flight paths.

Use this e.g. to make a floating object jitter.
